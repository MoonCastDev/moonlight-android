MoonCast: how screens and controllers reach the PC game

Every arrow to the PC is a Sunshine session: one device connected to the game. Sunshine gives each session its own virtual gamepad, so each session that sends a controller is a separate player.

Picture (video + sound) to a screen Controller to the PC Controller relayed through the TV (fallback) Picture sent but thrown away (controller-only session)

A · Two players, each on their own screen

Tested today: Retroid + Odin on the same Desktop game

B · The game on the TV, handhelds as controllers

Player 1 sends the game to the TV; player 2 taps "Join MiTV-AESP0 as player 2" (built, not yet tested on the TV)
Why a "controller-only session": Sunshine only takes controllers from a device that's connected to the game. So each handheld connects with the smallest stream it can (640×360, 15 fps, 0.5 Mbps), never decodes the picture, and sends only its buttons. That's straight to the PC, skipping the TV's Wi-Fi hop. Player 2 must be paired with the PC; player 1's TV relay is player 1's only.

C · PS5 or Xbox on the TV: one controller

Remote Play gives one controller per console, so there's no player 2
